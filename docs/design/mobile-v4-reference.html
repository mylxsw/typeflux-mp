规则

  • 玻璃只用于浮层：顶部按钮、输入框、弹出卡片、侧栏；内容区保持实底。
  • 颜色只有一种强调色，紫色专属最高推理档，绿色只表示“完成”。
  • 尺寸：控件 34 pt，圆形按钮 44 pt，页边距 20–22 pt，卡片圆角 18–20 pt，输入框 26 pt。
  • 动效：Orb 8 秒一轮，听写时加速；减弱动态效果时静止。
