## 素材与真实数据

- `assets/design/v4/*.svg` 从原稿 `<symbol>` 和 Apple 内联 SVG 原样提取；
  small/xsmall 仅应用源 CSS 指定的 1.9/2.4 描边，其他图标为 1.7。
- Orb 使用原稿 96 采样点、0.07 波动、0.62 静态相位和渐变算法，支持减少动态效果。
- 浅深色调色板、三层背景渐变、玻璃 blur24/saturate1.7、圆角与字号来自源 CSS。
- 套餐及积分读取 `/billing/subscription` 和 `/usage/current-period/stats`；
  积分直接使用接口单位，不因设计示例有小数而虚构数值。失败/缺失不显示假零余额。
- 模型、视觉能力、档位、上下文、价格由目录接口提供，截图目录仅为离线对照样本。
- 复制保留原文；分享由用户点击后打开系统分享菜单；语音结果进入可编辑草稿，不自动发送。
- 图片、表格、代码和工具结果沿用真实消息解析；设计图中的插图仅存在于测试 fixture。
- 本地语音错误的重试不重新初始化账号、不清空草稿；切后台保留可复制的部分识别结果。
  Windows 延迟插入在执行前检查页面/操作是否仍有效，避免退出后迟到写入。

## 视觉检查与证据边界

截图来自实际 Flutter widget，在 392×852 视口以 2× 导出，使用离线模拟账号/消息，
宿主预览字体为 SFNS 与 PingFang；它们不是 iOS/Android 真机截图。

代码字体、模型浮卡背景状态、搜索图标拉伸及设置值对齐。
小屏、大字号、英文、键盘区域和错误恢复另有组件测试。
