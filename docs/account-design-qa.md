# 账户设计方案实现与检查

本轮按用户确认的组合执行：图二的登录、注册，图一的设置。参考图保存在
`design/account-flow-approved.png`，开发前补齐的页面状态规范见
`design/account-flow-states.md`，开发顺序见 `account-implementation-plan.md`。

## 已完成

- 登录、创建账户、邮箱验证码、验证码重发倒计时、找回及重设密码。
- 分组设置页：真实账户资料、修改密码、外观、语言、高级设置、退出登录。
- 外观支持跟随系统、浅色、深色；语言支持跟随系统、简体中文、English。
  选择立即应用并保存，重启后恢复；写入失败会回退并提示。
- 修改密码成功后退出会话，回到登录页；刷新令牌失效也会回到登录页。
- 高级设置在登录前允许更换服务地址；已登录时显示当前地址及退出提示。
- 输入校验、错误提示、防重复提交、密码显示切换、自动填充及键盘滚动。
- 保留 v3 聊天布局；Windows 账户入口共用新设置页。本轮没有新增 Windows
  语音能力，也没有改动 Swift macOS 或后端仓库。
