# 移动端设计稿 v3 实现与检查

本轮以用户提供的 `mobile-v3-reference.html` 为依据，优先还原 iOS / Android
聊天体验。Windows 完成 macOS 风格的基础布局对齐，仍有原生功能验收工作。
原有 Swift macOS 工程未改动。

## 已实现的设计与交互

| 页面或组件 | 实现情况 |
| --- | --- |
| 新对话 | 88 点流动色滴、三张建议卡、独立返回 / 新建按钮 |
| 输入框 | 蓝灰玻璃层、28 点圆角、图片 / 文件附件、统一模型入口；手机无麦克风按钮 |
| 推理选择 | 272 点浮卡、44 点触摸区域、真实可用档位、自动重置、最高档紫色 |
| 模型选择 | 330 点浮卡、53 点列表行、能力 / 上下文 / 输出 / 倍率；选择后返回推理页 |
| 图片兼容性 | 附件保留在输入框；不支持图片的模型置灰，发送前再次校验 |
| 消息阅读 | 浅蓝用户气泡，回答正文展开，Markdown 表格横向滚动 |
| 思考与工具 | 读取真实事件，运行时展开、完成后收起；待原设备处理时明确提示 |
| 历史列表 | 搜索已加载会话、日期分组折叠、选中态、真实账户名、退出登录 |
| 回答进行中 | 空草稿显示停止，有草稿显示发送；追加指令通过真实 steer 接口处理 |
| 中断恢复 | 原消息 ID 幂等重试；未读追加消息可恢复，不因下一次发送而消失 |
| 深色 / 大字号 | 独立深色颜色，紧凑屏幕可滚动，输入框和浮卡随键盘区域上移 |
| 平板 | iOS / Android 按移动平台分流，不因为宽度而出现 PC 录音入口 |
| PC 基础 | 可收起侧栏、历史搜索、标题胶囊、阅读列、玻璃输入框，保留 Windows 语音入口 |

色滴轮廓、48 个曲线控制点、渐变方向和 8 秒周期直接移植设计稿算法；主要
导航图标沿用设计稿的细线 SVG 路径。系统的“减少动态效果”会停止色滴动画。
模型和计费数据来自接口；缺失时不显示编造的限制、套餐、积分或完成状态。

## 设计适配与明确边界

- HTML 设备外框为 393 × 852，其中边框占 6 点，内容为 381 × 840。
  Flutter 预览使用 381 × 840 内容尺寸、安全区顶部 54 / 底部 21。
- 不绘制假状态栏、灵动岛、底部指示条或假键盘；这些由真实设备系统提供。
  键盘测试通过 286 点 `viewInsets` 验证浮卡和输入框的几何位置。
- 缩小窗口或放大字体时允许内容滚动；不通过压缩文字和触摸区域来硬塞布局。
- 历史列表接口不提供所有会话的运行状态，因此只有已确认的当前运行会话能显示蓝点。
  账户接口没有可核实套餐信息时不填入设计稿中的演示 `Free` 标签。
- 历史消息指向“默认模型”但没有实际执行模型时，不推测当时的模型名称。
- 需要原设备模型的未发送指令可能只保存在手机本机缓存，会明确标注并提供复制；
  不宣称这些本机草稿已同步到 Mac。退出账户将按既有策略清理本机缓存。
- 登录、订阅和原生系统语音交互不在这份移动聊天设计稿的完整规格内。
  PC 本轮是基础视觉对齐，不能视为 macOS 全功能复刻。

## 检查方法与证据范围

`test/mobile_design_test.dart` 覆盖设计稿九种状态，以及 320 点宽、1.6 倍字号。
测试真实操作模型切换 / 推理调整 / 自动重置 / 图片兼容 / 历史搜索 / 引用保留
草稿 / 运行中发送，并检查键盘区域的位置。`test/chat_widget_test.dart` 另外
检查 320 / 390 / 1000 / 1200 宽度的平台分流与输入。

生成 PNG 使用实际 Flutter 组件、生产主题和离线测试数据；中文预览字体使用
宿主 STHeiti，系统运行时使用各平台默认字体。所有数据都是合成样例，不是
生产账户内容或真实计费结果。预览不等于 iOS、Android 或 Windows 实机截图。

已对照 HTML 参数人工查看新对话、推理浮卡、模型列表、回答、工具运行、历史、
暗色、不可调模型、键盘避让和紧凑布局。修复了灰色选择背景过宽、模型行高偏大、
桌面预览字体未继承、滑杆无障碍值缺失等问题。

浏览器参考截图没有完成：当前没有可用的自动化浏览器，Chrome 的计算机控制
访问未获授权。本轮使用 HTML 原始参数与 Flutter 渲染结果核对，未宣称完成
浏览器逐像素比对。原生字体、键盘动画、触觉、系统分享、浏览器切换和玻璃效果
仍需要真机验收。详见 `validation.md` 的平台构建限制。

## 复现预览

```sh
TYPEFLUX_RENDER_DIR=/absolute/output/directory flutter test \
  test/mobile_design_test.dart test/chat_widget_test.dart
```

可用 `TYPEFLUX_PREVIEW_FONT=/absolute/path/to/a/chinese-font.ttf` 指定宿主字体。
默认字体路径仅用于 macOS 上的离线截图测试，不打包进 App。
